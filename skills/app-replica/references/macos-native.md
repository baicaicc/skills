# 原生 macOS App：实机层的做法与坑

2026-10-30/31 复刻 Typeless（语音输入，菜单栏 App）时踩出来的。网页类 App 用不上这页。

## 测试分三层

| 层 | 换掉什么 | 验什么 | 什么时候跑 |
| --- | --- | --- | --- |
| 1 无头 | 时钟、麦克风、系统（按键/粘贴/前台 App）、后端全是假的 | 状态机与时序、插入内容、剪贴板恢复、历史 | 锁定测试，每次验收命令 |
| 2 实机 | 只把麦克风换成音频文件（如 `--test-audio x.wav`） | 真按键、真粘贴、真后端；和 L1 同一套实验 | 实机验收，空闲窗口执行器 |
| 3 真外设 | 不换 | 真麦克风、首字不丢、静音其他声音 | 最终构建后跑一轮 |

第 2、3 层用的合成按键要和 L1 驱动原版时同一套（同一个驱动程序），否则「原版认、复刻不认」测不出来。

## 授权

- **ssh 起的进程用的是 sshd 的授权**（`sshd-keygen-wrapper` 在辅助功能里开着时，ssh 起的任何程序都显得「已授权」）。最终验收要把安装包装进 `/Applications`，用 `open` 正常启动跑一轮。
- **ad-hoc 签名每次重新打包，授权都会失效**：授权绑在代码签名的 cdhash 上。所以授权放在最终构建之后做；之后再改代码，就要重新授权。
- **系统设置里加授权可以自动化**（用户本机已备好免密授权时；常设授权里写了就不问）：
  1. `open "x-apple.systempreferences:com.apple.preference.security?Privacy_Accessibility"`（录屏是 `Privacy_ScreenCapture`）。
  2. 用 AX 按描述为「添加」的按钮。打开面板是远程视图，不进 AX 树；等 CGWindow 列表里出现属于「系统设置」、layer 8 的窗口，实测 3–10 秒。
  3. 激活系统设置，键入 `/` 弹出「前往」框，再键入 `Applications/<App>.app`，回车。面板会直接选中这个 App 并关闭。
  4. 列表里会出现标识为 `<App 名>_Toggle` 的开关。值为 0 就用 AX 按一下，然后读回确认值为 1。
  5. 打开辅助功能后，输入监控随之生效（CGEventTap 用 defaultTap）。麦克风没有「添加」按钮，靠 App 第一次用麦克风时系统弹框授予。
- 用 App 自己的自检（如 `--smoke` 输出 `accessibility / inputMonitoring / microphone`）读回授权结果，用 `open -n -W --stdout <文件> -a <App> --args --smoke 2`，这样归属是 App 本身。

## 动了用户的机器，要原样还原

- **剪贴板**：测试前把所有条目、所有类型原样存成文件，测完写回，再比一次是否一致。不能用 `pbcopy` 写哨兵值：Typeless 那次覆盖了用户的剪贴板，内容没能找回。
- **声音与设备**：记下原来的音量、静音、默认输入设备，测完恢复。用外放代替麦克风回环（原版不列虚拟声卡时）。外放期间要关掉被测 App 的「录音时静音其他声音」，否则测试语音也被静掉；这一项单独用不出声的方法测。
- **被测 App 的默认行为**：「开机启动」默认开的，测前在设置里关掉，避免在用户机器上登记登录项。首次正常启动会弹引导窗、抢前台，插入类测试前先走完引导。
- **原 App**：测复刻版前退出原 App，因为它们抢同一个快捷键。测完重新打开原 App，并把测试期间改过的原 App 设置改回来。
- **浏览器**：只在用户的浏览器已经开着时测。测试页用本地 html 文件（`data:` URL 的窗口标题不进 AX），读回用全选加复制，之后恢复剪贴板。测完只关这个页。

## 常见的坑

- **合成的修饰键事件不带设备位**（分不出左右 Shift）。复刻要按键码认修饰键（左 Shift 56、右 Shift 60），不能只看设备位。
- **本地网络隐私**（macOS 15 起）：App 访问局域网 IP 会被拦，报 -1009 "Local network prohibited"；tailnet（100.64.x）不受影响。后端优先给 tailnet 地址。Info.plist 要写 `NSLocalNetworkUsageDescription`，并配 ATS 的 `NSAllowsLocalNetworking`。这类错误要报成「本地网络权限」，不能报成「断网」。
- **测试工具**：MacBook 上 CLT 的 swiftc 坏了时，在另一台 Mac 上交叉编译 x86_64 再传过去；AppleEvent 给 TextEdit 会超时，打开文档用 `open -a TextEdit <文件>`，读正文用 AX。
- **只杀自己起的进程**：记下 pid 再杀。宽泛的 `pkill -f` 曾经顺手杀掉了 launchd 管着的生产后端。
