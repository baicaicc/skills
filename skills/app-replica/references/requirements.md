### 健壮性与防护

文件类 App 的默认项，别的类型按同样思路改写。每项都要有测试（`tests/features/guard-*.spec.ts`，或原生自测）。

| # | 需求 | 检查 |
| --- | --- | --- |
| H1 | 只读写授权范围：对话框选中的文件或文件夹（含子树）、系统打开事件和命令行传入的文件、应用自己的数据目录、用户选定的导出位置；文档引用的图片只限文档所在目录的子树；范围外一律拒绝 | |
| H2 | 文件大小有上限（定一个数，如 32 MiB）：超限时提示并拒绝打开，不卡死 | |
| H3 | 符号链接与目录扫描有边界：不跟随指向所选目录外的链接，扫描有深度和数量上限 | |
| H4 | 外部修改冲突不丢字：文件在磁盘上被别的程序改了，提示用户，两边的内容都不丢 | |
